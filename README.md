# Receitas da dupla

Laboratório 3 de GitHub Flow, feito individualmente. Usei uma branch por receita, ajustei os textos em novos commits e integrei as duas por Pull Requests.

## Receitas

- [Bolo de cenoura](receitas/bolo-de-cenoura.md)
- [Pão de queijo](receitas/pao-de-queijo.md)

## Como usei o GitHub

Criei uma branch para cada receita. Em cada Pull Request, deixei uma descrição com o que mudou, o motivo da mudança e o arquivo que precisava ser conferido. Depois de reler o preparo, registrei as correções em novos commits e juntei as branches à `main`.

## O que aprendi

Separar as receitas em branches facilitou a comparação das mudanças. Por exemplo, eu consegui adicionar uma dica sobre a textura da massa sem alterar o restante do projeto. Se eu quiser descobrir quando uma instrução mudou, posso abrir o histórico ou a aba **Files changed** do Pull Request. O trabalho foi feito na versão individual.
